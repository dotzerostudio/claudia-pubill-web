# Claudia Pubill · Web

Web de Claudia Pubill, psicóloga en Barcelona y por videollamada. Está en catalán, español e inglés.

HTML estático, sin build. Para verla en local:

```bash
python3 -m http.server 8000
```

y abre http://localhost:8000.

**Publicar en Cloudflare Pages:** conecta este repositorio, sin comando de build y con la carpeta de salida `/`.

**Antes de abrirla al público:** rellena los datos entre corchetes, pon el WhatsApp real y el enlace de Cal.com, y quita el `noindex` de `index.html`. Todo está explicado en `CLAUDE.md`.
